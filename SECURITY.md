# Vault security

Use [private reporting in vault-source](https://github.com/kryptocorelabs/vault-source/security/advisories/new). Include the affected Vault and Firefox versions, expected impact, and a reproduction using synthetic data.

The [source security policy](https://github.com/kryptocorelabs/vault-source/blob/main/SECURITY.md) defines scope and response targets. The [Vault threat model](THREAT_MODEL.md) describes trust boundaries. The [recovery version guide](RECOVERY-HARDENING.md) identifies what each public build includes.
